# Network Graph Visualizer

Interactive network graph visualization tool for connecting anything.

## Features

- 🎨 Beautiful D3.js force-directed visualization
- 🖱️ Drag nodes, hover for details, click to inspect
- 📊 Multiple node types (person, organization, event, technology)
- 🔗 Create and visualize relationships
- 💾 Import/Export JSON data
- 🎯 Real-time statistics
- 📱 Fully responsive

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Usage

1. **Add Nodes** - Use the control panel to create nodes
2. **Create Links** - Select nodes and connect them
3. **Import Data** - Load JSON graph data
4. **Inspect** - Click nodes to see details

## Tech Stack

- Next.js 14
- TypeScript
- D3.js for visualization
- Tailwind CSS
- Framer Motion for animations
- Zustand for state management
